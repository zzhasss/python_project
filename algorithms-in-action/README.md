# «Алгоритмы в действии» — данные проекта

Тема проекта: интерактивный веб-сервис для визуализации алгоритмов и структур данных
(Python 3, Flask, HTML/CSS, JavaScript). Сервис показывает линейный и бинарный поиск,
сортировки пузырьком, вставками и быструю, а также обходы графа BFS и DFS.

## Актуальность

Алгоритмы и структуры данных входят в базовую подготовку по информатике и программированию.
Их знание проверяют на экзаменах, олимпиадах и технических собеседованиях. Студентам при этом
трудно по тексту и псевдокоду представить, как алгоритм работает на практике: как
сокращается диапазон в бинарном поиске, почему быстрая сортировка иногда работает медленно,
чем порядок обхода BFS отличается от DFS. Пошаговая визуализация показывает каждое действие
алгоритма на конкретных данных, и это помогает разобраться в материале.

Готовых открытых наборов данных о выполнении алгоритмов нет. Поэтому данные для проекта
сгенерированы: это входные данные разных типов и записи о том, как алгоритмы на них
отработали. Такие данные нужны и для работы самого сервиса (он воспроизводит записанные
шаги), и для сравнения алгоритмов между собой.

## Что является данными

1. **Входные данные алгоритмов** — массивы и графы, которые пользователь выбирает или задаёт
   в интерфейсе.
2. **Пошаговые трассы** — записи о каждом действии алгоритма (сравнение, обмен, посещение
   вершины и т.д.) вместе с состоянием массива или очереди на этом шаге. По этим записям
   сервис строит анимацию с запуском, паузой и пошаговым просмотром.
3. **Результаты запусков** — число операций и время работы каждого алгоритма на входах
   разного размера и типа.

## Как получены данные

Данные сгенерированы скриптом `src/generate_data.py`. Алгоритмы реализованы в
`src/algorithms.py`, генераторы массивов и графов — в `src/generators.py`.
Используется фиксированный `seed = 42`, поэтому при повторном запуске получаются те же данные:

```bash
python src/generate_data.py
```

Сторонние библиотеки не нужны, достаточно Python 3.

## Файлы

Все файлы лежат в папке `data/` в формате CSV (кодировка UTF-8, разделитель — запятая).

| Файл | Строк | Содержание |
|---|---|---|
| `arrays.csv` | 1015 | 30 входных массивов, по одной строке на элемент |
| `graphs.csv` | 27 | список графов и их параметры |
| `graph_nodes.csv` | 287 | вершины графов с координатами для отрисовки |
| `graph_edges.csv` | 526 | рёбра графов |
| `traces.csv` | 41 | список пошаговых трасс |
| `trace_steps.csv` | 1687 | шаги выполнения алгоритмов |
| `sorting_runs.csv` | 315 | запуски сортировок |
| `search_runs.csv` | 540 | запуски поиска |
| `graph_runs.csv` | 318 | запуски обходов графа |

## Описание столбцов

### arrays.csv
| Столбец | Описание |
|---|---|
| array_id | идентификатор массива, например `random_10` |
| array_type | `random` — случайный, `sorted` — отсортированный, `reversed` — по убыванию, `nearly_sorted` — почти отсортированный (~5% элементов переставлено), `few_unique` — только 5 различных значений |
| size | размер массива (8, 10, 15, 20, 50, 100) |
| position | индекс элемента |
| value | значение элемента (1–99) |

### graphs.csv
| Столбец | Описание |
|---|---|
| graph_id | идентификатор графа, например `cycle_10` |
| graph_type | `path` — цепочка, `cycle` — цикл, `star` — звезда, `complete` — полный, `binary_tree` — бинарное дерево, `grid` — решётка, `random_sparse` — случайный разреженный, `random_dense` — случайный плотный, `disconnected` — две компоненты связности |
| directed | ориентированный ли граф (все графы неориентированные) |
| n_nodes, n_edges | число вершин и рёбер |

### graph_nodes.csv
`graph_id`, `node_id`, `label` — подпись вершины, `x`, `y` — координаты на холсте 600×400.

### graph_edges.csv
`graph_id`, `edge_id`, `source`, `target` — концы ребра.

### traces.csv
| Столбец | Описание |
|---|---|
| trace_id | идентификатор трассы |
| category | `sorting`, `search`, `graph` |
| algorithm | `bubble_sort`, `insertion_sort`, `quick_sort`, `linear_search`, `binary_search`, `bfs`, `dfs` |
| input_id | ссылка на `array_id` или `graph_id` |
| target, case | искомое значение и его позиция: `first`, `middle`, `last`, `absent` (только для поиска) |
| n_steps | число шагов в трассе |
| comparisons, swaps, writes | число сравнений, обменов и записей в массив |
| result | результат: отсортированный массив, найденный индекс или порядок обхода вершин |

### trace_steps.csv
| Столбец | Описание |
|---|---|
| trace_id | ссылка на `traces.csv` |
| step | номер шага |
| step_type | тип действия: `compare`, `swap`, `shift`, `insert`, `select_key`, `pivot`, `pivot_placed`, `mark_sorted`, `go_left`, `go_right`, `found`, `not_found`, `enqueue`, `dequeue`, `push`, `visit`, `tree_edge`, `skip_edge`, `skip_node`, `done` |
| index_1, index_2 | индексы элементов массива, участвующих в шаге |
| value, target | текущее значение и искомое значение |
| low, high, mid | границы рассматриваемого диапазона (бинарный поиск, быстрая сортировка) |
| node, parent | текущая вершина и вершина, из которой в неё пришли |
| edge_from, edge_to | просматриваемое ребро |
| level | уровень вершины в BFS |
| frontier_state | содержимое очереди (BFS) или стека (DFS) через пробел |
| visited_state | посещённые вершины в порядке обхода |
| array_state | состояние массива после шага, элементы через пробел |

Пустая ячейка означает, что для этого типа шага значение не используется.

### sorting_runs.csv
| Столбец | Описание |
|---|---|
| algorithm | алгоритм сортировки |
| input_type | тип массива (как в `arrays.csv`) |
| n | размер массива: 10, 50, 100, 250, 500, 1000, 2000 |
| run, seed | номер повтора (0–2) и seed, из которого сгенерирован массив |
| comparisons, swaps, writes | число сравнений, обменов и записей |
| max_stack_depth | наибольший размер стека подзадач (только `quick_sort`) |
| time_ms | время выполнения, мс |

### search_runs.csv
| Столбец | Описание |
|---|---|
| algorithm | `linear_search` или `binary_search` |
| n | размер отсортированного массива: 10 – 100 000 |
| case | позиция искомого: `first`, `middle`, `last`, `absent`, `random` (50 случайных запросов) |
| query, target | номер запроса и искомое значение |
| found_index | найденный индекс, -1 — не найдено |
| comparisons, time_ms | число сравнений и время, мс |

### graph_runs.csv
| Столбец | Описание |
|---|---|
| algorithm | `bfs` или `dfs` |
| graph_type, n_nodes, n_edges | тип и размер графа (10 – 1000 вершин) |
| run, seed | номер повтора и seed генерации графа |
| visited | число вершин, достигнутых из вершины 0 |
| edges_examined | число просмотренных рёбер |
| max_frontier | наибольший размер очереди (BFS) или стека (DFS) |
| bfs_levels | число уровней обхода (только BFS) |
| time_ms | время выполнения, мс |
